# 💻 Projeto quiz de programação 💻
- Um projeto de quiz interativo focado em lógica e linguagens de programação. Atualmente, o projeto está em desenvolvimento.
### O projeto conta com:
- perguntas sobre linguagens de programação
- Feedback do usuario
- Link com redes socias
- Front-end em CSS
- Back-end com Python e Flask
- Banco de dados Integrado com SQLAlchemy e PostgreSQL
